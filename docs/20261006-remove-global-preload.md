# 清理全局业务数据预加载

- 移除销售、数据中心、财务、公告、司机、分货、仓库、餐厅公共布局中的 `hydrate()` 调用。页面保留各自的 API 请求和原有权限校验。
- 当前页面及组件没有业务数据依赖旧 `lib/store.ts`；导航退出操作移除旧 `StoreAPI.setRole(null)`，不再重新写入业务缓存。
- 成功登录及退出时清除历史 `veggie_demo_store` 缓存，不影响语言、收藏或 Cookie 偏好。
- 报价列表保留服务端分页、客户精简信息、行程展示和当前页开票状态请求；不再因进入公共布局读取库存流水、价格表、采购、波次、完整客户表和未筛选订单。
- 现有会话的历史缓存会在下一次登录或退出时清除；本次不修改服务端数据权限或删除数据库记录。

回归测试：`npx tsx --test tests/no-global-preload.test.ts`；类型检查：`npm run typecheck`。

验证结果：3 项回归测试、类型检查、登录页及会话工具的 ESLint 检查通过。使用本地开发服务和模拟 API 的浏览器检查，确认报价及销售单页面没有公共预加载请求，登录清除了旧缓存并保留无关偏好；页面脚本无异常。开发环境 Strict Mode 可能重复执行页面自身请求，不属于被移除的全局预加载。

本次修改尚未提交或部署到生产。
