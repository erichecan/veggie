📋 1. 销售订单 / 报价单
▼
P0 紧急
订单直接编辑（无需取消重建）
已确认但未验证的订单允许：修改数量、删除行项、新增行项。自动调整虚拟库存。无需先取消再重新创建。
来源：2026-05-22 会议 #4、ODOO-REPLICATION P1-6
低库存告警（醒目弹窗/徽章）
当商品库存低于安全阈值（默认：20）时，在下单页面显示醒目的告警提示。当前实现存在但不够醒目。
来源：2026-05-22 会议 #3、BUSINESS-FLOW P0
批次级别缺货预警
接口：GET /api/waves/[id]/shortage。对比批次总需求量 vs 当前库存。显示缺货商品及缺口数量。
来源：DEV-PLAN P0-1、BUSINESS-FLOW P0
P1 重要
报价单详情页（Odoo 1:1 复刻）
8 个区域：面包屑、操作栏、状态流、主信息、标签页（订单行/可选项/备注）、17 列订单行表格、合计栏、Chatter。所有状态共用统一模板。
来源：ODOO-REPLICATION 11.9
运营操作下拉菜单（Action）
操作项：确认报价单、取消、批量验证、批量编辑。共用统一操作栏。
来源：ODOO-REPLICATION P1
订单审计日志 UI（时间线）
显示谁在什么时间修改了哪个字段。订单详情页上的时间线组件。Chatter 组件支持"发送消息"/"记录备注"/"安排活动"。
来源：DEV-PLAN P1-5、ODOO-REPLICATION Chatter
确认后安全编辑（字段级权限）
字段级权限矩阵：每个状态下哪些字段可编辑。防止意外修改已锁定的字段。
来源：DEV-PLAN P1-6
批量确认报价单
选择多个待处理（PENDING）报价单，一键确认为已确认（CONFIRMED）。记录 confirmationDate。
来源：WORKFLOW-PRD 步骤 3、业务流程文档
已确认回退为待处理
允许运营将已确认的订单回退为报价单（PENDING）状态以便重新编辑。
来源：业务流程文档 第 3 节
实时库存锁定（多销售员并发）
销售员录入订单时，显示已被其他订单锁定的库存。例如：在手 1107，已锁定 1105，可用 = 2。
来源：2026-05-22 会议 #3
P2 计划中
批量编辑对话框
跨选中订单批量修改字段：配送批次、配送日期、付款方式。
来源：ODOO-REPLICATION P2
批量验证配送
一次性验证多个订单的配送。从当前 20 单上限提高到 50-100 单。
来源：ODOO-REPLICATION P2、2026-05-22 会议 #6
订单状态扩展：LOCKED + CANCELLED
新增 LOCKED（开票后锁定）和 CANCELLED（已取消）状态枚举。sentAt、lockedAt 时间戳字段。
来源：ODOO-REPLICATION Schema

💰 3. 定价引擎 / 价格表
▼
P0 紧急
三级定价优先级
优先级：客户专属价（CustomerSpecialPrice）> 价格表项（PricelistItem）> 商品基础价（Product.listPrice）。提供 resolvePrice() 和 resolveCustomerPrice() 接口。
来源：pricing-module-prd.md
客户专属价（CustomerSpecialPrice）
按客户、按商品设置固定价格覆盖。提供管理专属价的增删改查 UI。
来源：pricing-module-prd.md
价格表项（多种计算类型）
PricelistItem：适用范围（全局/分类/商品/变体）x 计算类型（固定价/百分比/公式）。条件：最低数量、开始日期、结束日期。
来源：pricing-module-prd.md
P1 重要
公式定价（基准 x 折扣 + 加价）
公式：基准价（列表价/标准价/价格表）x (1-折扣%) + 加价，支持利润保护（最低利润 min_margin）。
来源：pricing-module-prd.md
价格表管理 UI（Odoo 紫色主题）
经典 Odoo 风格的价格表增删改查页面。列表视图 + 详情视图。
来源：pricing-module-prd.md
下单时自动填充价格
添加商品到订单时，自动从定价引擎解析价格并预填单价字段。
来源：pricing-module-prd.md、业务流程文档
📦 4. 采购管理
▼
P0 紧急
采购建议引擎（自动生成）
PurchaseSuggestion 模型。根据需求量 vs 库存自动生成采购建议。接口：GET /api/purchase-suggestions。
来源：DEV-PLAN P0-2
采购单 PDF/Excel 导入
上传供应商发票/送货单的 PDF 或 Excel，系统自动识别并生成采购单草稿。人工审核后确认。
来源：2026-05-22 会议 #1
从历史采购单"再次采购"
复制上一次采购单，保留供应商和商品列表，仅修改数量。
来源：2026-05-22 会议 #1
P1 重要
采购单完整工作流
完整采购单生命周期：草稿 > 已发送 > 已确认 > 已收货 > 已开票。包含状态流转和库存联动。
来源：2026-05-22 会议 #2、业务流程文档
采购确认自动更新库存
确认采购单 -> 增加预测量。验证收货 -> 增加在手量。验证后，采购单锁定（仅能通过退货/报废编辑）。
来源：2026-05-22 会议 #2
供应商管理（isVendor 标记）
Customer 模型增加 isVendor=true 标记供应商。供应商增删改查，关联采购单。
来源：ODOO-REPLICATION、业务流程文档
P2 计划中
采购单计划日期（到货日 vs 创建日）
采购单创建日期和实际到货日期可以不同。库存批次日期应跟随计划日期，而非采购单创建日期。
来源：2026-05-22 会议 #12
