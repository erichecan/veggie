# 配送回单、司机收款、开票与 Credit Note 闭环

## 目标

以订单行和配送日为主线，把司机现场签收/收款/退货、纸质回单、仓库验收、销售处理、会计开票与收款入账串成可追踪流程。不能用定时器替代业务确认，也不能因司机上报就直接改变库存或生成贷记。

## 业务记录与责任边界

| 阶段 | 责任人 | 必须留下的记录 | 完成条件 |
| --- | --- | --- | --- |
| 配送与签收 | 司机 | 行程、司机、车牌、送货时间、客户/订单、签收人和签名、实收金额与方式 | 站点已签收，或已报告未送达/异常 |
| 退货/换货上报 | 司机或调度 | 原订单（可选；无法确认时留待仓库匹配）、应送商品、实际退回商品、数量、原因、照片、上报时间 | 退货记录进入仓库待验收 |
| 实物验收 | 仓库 | 实际商品和数量、质量、可再售/报废、验收人和时间 | 验收通过或拒绝；通过后转销售处理 |
| 销售处理 | 销售 | 接受/拒绝原因、折让或补送安排、Credit Note 申请金额和明细 | 明确作出业务决定并提交；会计可看到决定人、时间和待办 |
| 回单核对与开票 | 会计 | 纸质回单核对结果、实送数量、司机报告、差异说明 | 无待处理差异后确认回单，生成发票草稿 |
| 发票过账及收款 | 会计 | 发票审核/过账、实收款核对、收款方式、对应发票分配 | 发票过账后，收款分配到当日或历史应收并生成凭证 |
| Credit Note | 销售、会计 | 关联客户、原订单/原发票、核实数量、原因、申请与审核记录 | 会计审核确认后生成贷记单；抵扣/退款另记分配凭证 |

## 发票时点

1. 司机结束配送后，订单只是“已配送”，不能因此直接成为正式应收。
2. 会计核对纸质回单、司机手机报告、实送数量和退货状态后，将回单确认为已核销。
3. 系统在核销时按最终 `deliveredQty` 幂等生成发票草稿，发票业务日期仍为配送日期；草稿由会计检查后过账。
4. 24 小时或周末规则只用于提醒待办。周五数据在下一个工作日继续显示；不能到点自动越过差异、验收或销售审核。
5. 已有未完成的退货处理或销售贷记申请时，发票保持待开票；处理完成后补开。已过账发票的退货/折让通过关联原发票的 Credit Note 修正。

## 同日与历史退货

- 同日未开票退货：按最终实送数量开票，不生成 Credit Note。
- 已开票的退货：仓库先验收实物，销售审核后提交申请，会计确认生成关联原发票的 Credit Note。
- 送错商品：同时保留原订单商品与实际退回商品；仓库验收后，销售决定补送正确商品或申请贷记。补送商品通过新订单追踪。
- 找不到原订单：建立未匹配退货/入库记录，仓库登记车辆、司机、客户和商品，销售核查来源；匹配前不减少任何历史订单数量。
- 价格/质量折让但无实物退回：销售仍需提交原因、金额和原订单/发票，会计审核；不影响库存。

## 司机实收与入账

- 司机按客户站点记录实际收到金额和收款方式；金额为零也必须明确填写零，避免“未上报”和“确实没收款”混淆。
- 会计以司机报告的实收为入账依据，以订单/发票金额为核对参照。少收保留应收；超收先核销历史欠款。超过客户全部已过账发票余额的部分，本次实现会阻止司机交账确认，要求会计先通过现有预收/手工收款流程单独登记，不能丢弃或强行核销。
- 收款不能在没有正式过账发票时静默消失。若关联发票仍是草稿，先过账或把收款记为可追踪的待分配款，再完成发票分配。
- 现金和银行转账使用各自的 Payment Journal；月结订单不是自动的“转账收款”。

## 状态与可见性

推荐的端到端状态：

`配送中 → 待回单核对 → 待仓库验收（如有退货） → 待销售处理（如有差异） → 待会计审核（如有贷记） → 待开票 → 发票草稿 → 已过账 → 已收款/部分收款`

每个待办必须可见订单/发票号、客户、配送日、司机、车牌、退货时间、商品及数量、原因、责任人、最近更新时间和已等待时间。销售完成后留下结构化决定与审核人/时间；会计通过“待销售处理”及“待会计审核”列表判断是否可以继续。

## 当前实现与本次补齐

- 当前已有：司机手机签名与退货上报、车牌和来源行程、仓库验收、销售审核、会计贷记申请审核、退货状态未结束时的开票拦截、回单核销后生成草稿发票、发票日期跟随配送日、司机收款会计确认和账本凭证。
- 修复前的风险：司机端已有每个客户站点的“实收金额”，但会计“司机收款确认”仍按订单理论金额和订单付款方式重新计算，未使用司机实际报告。这样会把月结/未收款订单当作在线转账，并可能和实际收款不一致。
- 本次实现重点：将司机站点实收金额及收款方式作为会计收款核对的来源；会计确认前检查报告完整性；显示报告实收与订单参考金额的差异；按实际方式生成现金或银行 Payment；关联发票仍为草稿或有超额收款时，不允许确认日结快照。未完成的退货和贷记申请也继续阻止开票/过账。

## 仍需业务运营执行的控制

会计必须对照纸质回单后再确认；若需记录纸质回单号码/照片、收款差额原因或预收款余额，应在后续财务凭证/收款界面补充专门字段，不能只依赖自由文本或司机理论应收金额。
