# 配送状态流转补充确认（2026-10-29）

本说明补充并覆盖 `docs/20260922-confirm-departure-需求原话.md` 中 22:00 仅自动确认出发的旧口径。

## 日间批次状态

- 打印拣货单后的 `pickLockedAt` 继续显示「🔒 拣货中」，这是拣货锁/作业状态，当前文案保留。
- 日销售中心的「确认全部出发」仍是约 17:00–18:00 的批次操作：结束拣货并确认离仓。波次设为已出发，订单变为 `IN_DELIVERY`（页面显示「在途」），拣货锁清除。
- 波次卡片显示「完成拣货 · 在途」，每笔订单显示「在途」。

## 22:00 自动完成

- 22:00 定时任务完成已出发波次；若当天已准备（已分配完成或已锁定）但漏点「确认全部出发」，先自动确认出发，再完成配送。
- 完成时设置波次 `completedAt`、订单 `COMPLETED`、行程 `COMPLETED`，并按既有全量送达规则回填实送数量。
- 日销售中心保留该日已完成波次，波次和订单状态显示「完成配送」。
- 配送调度中心移除人工「标记完成」按钮，避免多人重复操作；界面提示系统将在 22:00 自动完成。

## 状态一致性约束

- 活动波次订单进入 `IN_DELIVERY` 必须走波次确认出发流程；订单详情、批量开始配送、手动建行程等旁路对活动波次订单返回提示，不再只更新订单状态。
- 波次出发后拣货锁不可重新打开；拣货/分货页面不再列出已出发波次。
