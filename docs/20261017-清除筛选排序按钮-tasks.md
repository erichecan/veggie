# 全站「清除」按钮 —— 任务台账

需求原话见 `docs/20261017-清除筛选排序按钮-需求原话.md`。

调研结论：全站有三套互不兼容的筛选工具栏（`OdooControlPanel`+`lib/list-filters.ts`、
`components/boss/analytics-shared.tsx`、legacy `ReportingContext`），没有一套自带"一键清除"。
筛选状态全部是页面本地 `useState`，清除按钮哪怕放进共享组件，每个页面仍要自己写 reset handler。

范围边界（L2 自行判断，不升级）：
- 纯面包屑用途的 `OdooControlPanel`（无筛选）跳过：`operator/batch-analysis`、`operator/trips/[id]`、`operator/waves/[id]`
- 数据分析模块里只有「日期范围」一个维度的纯仪表盘（`sales-overview`/`internal-control`/
  `income-statement`/`procurement`/`driver-commission`/`logistics`/`ap-aging`/`ar-aging`）
  点预设按钮已经是"换一个值"而非"叠加筛选"，没有可叠加状态需要清除，跳过
- 客户列表截图标注的「type」= 页面里真实存在的「Price Type」列（截图本身就有这一列），不是
  Individual/Company 这个不存在的字段，按截图原样对应，不升级确认
