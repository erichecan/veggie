> 受众：运营人员（不懂代码）。读完这页，你能**独立完成新餐馆从建档到开票的全流程**。

## 场景 1：上架一个新商品（2 分钟）

1. 左上角导航 **商品** → 右上角 **新建**
2. 填写：
   - 商品名称（必填，如 "红萝卜 10kg BAG"）
   - 内部编号（SKU，如 "CAB"）
   - 商品分类（下拉选：蔬菜 / 中式蔬菜 / 香草 / 干货 / 调料 / 冷冻 / 肉类）
   - Sale Price（销售牌价）
   - Cost（成本价）
   - Product Type：
     - **Storable Product**（普通商品，追踪库存）✓ 默认
     - Consumable（消耗品，不追踪库存）
     - Service（服务，不追踪库存）
3. 上传图片（拖进去或点击选择，最大 5MB，支持 JPG/PNG/WebP/GIF）
4. **Sequence 号**（可选）：决定商品在发票打印和拣货单上的显示顺序
   - 同线路（如 M1、D15）客户按 sequence 排列打印，司机按顺序装车
5. 点 **保存**

### 保存后

- 商品自动可被下单、出现在所有相关 pricelist 的范围里
- 改价可以直接在列表里行内编辑

## 场景 2：给新餐馆建档（3 分钟）

1. 导航 **客户** → 右上角 **新建**
2. 基础信息（**必填**）：
   - 名称（餐厅名，如 "川味小厨"）
   - 地址
3. Sales & Purchases Tab（下方）：
   - **Price Type**（重要！）：
     - 👉 **Multi Price**：按下方 "Pricelist" 字段走价格表，**推荐**
     - Default Price：直接用商品牌价（适合散客）
     - Last Price：上次买多少，这次还多少（老客户波动价）
   - **Pricelist**：选一张价格表绑定
   - Commission Rate：司机送这家客户的佣金率（0.05 = 5%）
   - Commission Fixed：司机送这家客户的固定佣金（€/单）
4. Invoicing Tab：
   - 付款条款（Cash / Weekly / Monthly）
   - 信用额度
5. 保存

### 关键点：Price Type ≠ Pricelist

**Price Type 决定"用哪种策略"**，Pricelist 决定"具体多少钱"：

- Multi + 选 TAKEAWAY 菜价 → 走 TAKEAWAY 菜价的规则
- Default → 直接用商品牌价，忽略 pricelist
- Last → 系统查该客户上一次买这个商品的成交价

## 场景 3：新建一张 Pricelist + 配置（5 分钟）

**业务背景**：新餐馆 "川味小厨" 希望所有商品打 95 折，但红萝卜固定 €7、红辣椒固定 €6.5。

1. 导航 **价格表** → 右上角 **新建**
2. 填 Pricelist 名称："川味小厨菜价"
3. 往下滚到 **Pricelist Items** 表格 → 点 **Add a line**
4. 在弹窗里：
   - **第 1 条：全局 -5%**
     - Apply On = Global
     - Compute Price = Formula
     - Based On = Public Price
     - Price Discount = 5
     - 保存（**Save & New** 继续加下一条）
   - **第 2 条：红萝卜特殊价**
     - Apply On = Product Variant
     - Product Variant 下拉选 "Carrot 10kg BAG"
     - Compute Price = Fix Price
     - Fixed Price = 7.00
     - 保存
   - **第 3 条：红辣椒特殊价**
     - Apply On = Product Variant
     - 选 "Chilli Red KG"
     - Fix Price = 6.50
     - Save & Close
5. 点右上角 **保存** 完成整张 pricelist

### 挂到客户

1. 回到 **客户** 列表 → 找到 "川味小厨"
2. 点进去 → Sales & Purchases Tab
3. Pricelist 下拉选 "川味小厨菜价"
4. 保存

### 验证（强烈推荐）

回到 Pricelist 详情页底部有**价格预览**工具：
1. 选任意商品 + 数量
2. 点计算 → 显示"最终价格 €X，来自哪条规则"
3. 特殊商品（胡萝卜/红辣椒）应当显示固定价
4. 其他商品应当显示"Public Price -5%"

## 场景 4：复制一个 pricelist

开一个新餐馆，想基于现有的 TAKEAWAY 菜价改几条特殊规则？

1. 价格表列表 → 找到 TAKEAWAY 菜价行 → 点 **复制** 按钮
2. 自动跳转到新表的编辑页，items 已全部克隆过来
3. 改名（默认 "TAKEAWAY 菜价 (Copy)"）+ 调整 items → 保存

---

## 场景 5：pricelist items 太多怎么找

一张 TAKEAWAY 菜价有 72 条 items，想改其中一条胡萝卜的价：

1. 进 pricelist 详情 → Pricelist Items 区块
2. 搜索框输入 "Carrot" → 实时过滤
3. 或按 Apply On 筛选："Variant"
4. 点列头切换排序（Min Qty / 日期 / Price / Discount / Sequence）
5. 点行打开编辑弹窗 → 改 Fixed Price → 保存

## 场景 6：餐馆下单 → 出库 → 签收 → 开票（运营视角）

1. 等餐馆用手机下单
2. 导航 **订单** → 看到 "待拣货" 状态的订单
3. 勾选一批订单 → 点 **生成拣货波次**（会自动排好拣货顺序）
4. 系统自动创建一张拣货波次 + 对应的配送行程
5. 到 **配送行程** 指派司机
6. 司机用手机开始拣货/配送/签收
7. 订单完成后，到 **发票** → 对该订单点 **生成发票**
8. 发票详情 → **Post**（过账）→ 自动生成一张会计凭证（Dr AR / Cr Revenue + VAT）

## 常见错误提示

| 弹出的红色提示 | 意思 | 解决 |
|---------------|------|------|
| "库存不足" | 订单数量 > 现有库存 | 先去 **采购订单** 补货，或在 **商品** 调整库存 |
| "登录已过期" | JWT 7 天超时 | 重新登录 |
| "请求过于频繁" | 触发限流（登录 10/min） | 等 1 分钟再试 |
| "你没有权限执行此操作" | 当前角色不允许 | 换管理员账号 |
| "价格表被 N 个客户使用中" | 删除 pricelist 失败 | 先把那些客户改绑其他 pricelist |
