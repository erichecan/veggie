# 商品分类维护界面改版

## 界面与操作

- 桌面端使用一级、二级、三级三个并排面板。选择上级后展示子分类，面板显示分类数量及归属路径，选中分类高亮。
- 每栏提供对应等级的新增入口；一级、二级分类同时提供直接添加子分类入口。未选上级时，下级新增按钮禁用并显示明确提示。
- 新建弹窗明确显示等级和完整父级路径，自动确定归属；保存后选中新分类。手机端自动进入下一等级，便于连续创建。
- 编辑分类使用独立弹窗，保留中英文名称和所属分类调整；可选父级包含完整路径，排除自己、子孙和会导致超过三级的分类。
- 搜索支持中英文名称及祖先路径；搜索结果可以定位到分类所在层级。
- 手机端逐级浏览，面包屑返回上级或全部分类；桌面端始终保留三栏。
- 有子分类的删除按钮禁用；关联商品的删除仍由原有服务端校验阻止，失败时保持确认弹窗以便取消。
- 保留原有导入、导出及商品关联。未修改数据库结构，也未重新组织已有分类。

## 文件与验证

- 分类界面：`components/classic/ProductCategoryManager.tsx`，由设置页引用。
- 导航和有效父级计算：`lib/product-category-navigation.ts`。
- 回归单测：`tests/product-category-navigation.test.ts`，与已有分类树及价格规则测试一起纳入 `scripts/verify-product-category-mobile.sh`。
- 浏览器验证：`scripts/audit/verify-category-mobile.ts` 使用模拟 API，不修改真实分类。覆盖中英文 360、390、768、1440 宽度，以及三级创建、移动、删除、搜索、归属选项、关联商品删除失败和手机逐级创建。
- 可用 `CATEGORY_MOBILE_PREVIEW_URL` 指定本地服务，`CATEGORY_MOBILE_PREVIEW_OUTPUT` 指定截图输出目录。

验证结果：类型检查、36 项分类树/导航/价格规则测试、完整浏览器验证全部通过。修改文件 ESLint 无错误；设置页计量单位部分原有 `load` 的 Hook 依赖警告仍保留，不在本次分类改版范围内。本地模拟数据截图位于 `/tmp/veggie-category-manager-check`。

本次界面修改尚未提交或部署到生产。
