🚚 司机调度

职责:把当天确认的订单分给司机、安排拣货与装车、跟踪配送过程、处理途中异常

典型一天的工作流(每步对应的页面)

① 查看待配订单拣货波次页左侧「待分配」
→
② 分配订单给司机拖拽到司机波次卡片
→
③ 打印拣货单波次卡片「🖨 打印拣货单」
→
④ 监督分货装车分货页(按波次)
→
⑤ 发车跟踪配送单(Trips)页
→
⑥ 处理退货/异常退换货页

📦 运营人员

职责:接单/代客下单、维护商品与价格、管库存、下采购单、开发票——系统的主操作者

典型一天的工作流

① 接单/代客下单下单页(选客户→价格表→商品)
→
② 确认报价单报价单列表 → 确认转销售单
→
③ 移交调度销售单进入拣货波次池
→
④ 补货采购建议 → 下采购单 → 入库
→
⑤ 配送完成后开票发票页批量生成

📊 老板视角

职责:不做操作,只看生意——今天卖了多少、赚不赚钱、谁欠款、什么货走得快

典型使用场景

① 早上看总览经营总览(今日订单/金额 KPI)
→
② 看卖了什么销售分析(按商品/客户/业务员)
→
③ 看买了什么采购分析(按供应商)
→
④ 月底打报表销售报表(筛选+打印)

🧾 会计

职责:对钱——核对司机收回来的钱、确认交账、给客户对账开票、追欠款

典型一天的工作流

① 司机回来交账财务→司机交账确认
→
② 扫码核销送货单会计页(扫码枪批量核销)
→
③ 核对现金/转账财务总览 KPI
→
④ 周期对账客户对账单(生成→发送)
→
⑤ 开票收款发票(确认→已付)
