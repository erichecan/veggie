## 开工时发现的两件事（比原需求更严重）

**1. 生产上所有邮件其实一封都没发出去过。**
发件域 `veggiesupply.ie` 从来没在邮件服务商 Resend 那里验证过，每次发送都被拒。
受影响的是：客户下单后的订单确认信、管理员重置密码的通知信、发给供应商的采购询价单。

**2. 更糟的是，系统当时并不知道自己失败了。**
Resend 的开发库在失败时不报错，而是把错误"放在回信里"，代码只看有没有报错，
所以一路当成功往下走 —— 采购单会因此变成「已发送」状态，而供应商根本没收到过。

生产上那些状态是「已发送」的采购单，**供应商实际从未收到邮件**。这是已经发生的事实，
代码修不回来。要不要挑出来重发一遍，得你定。

现在这两个问题都修好了：发失败会明确报错，不会再假装成功。

## ⛔ 需要你做的两件事

**1. 让邮件真的能发到客户手里（否则以上功能在生产上全是哑的）**

去 Resend 后台（resend.com/domains）添加域名 `johnstonebros.ie`，
它会给你几条 DNS 记录（SPF、DKIM），加到域名解析里。
完成后在服务器的 `/etc/veggie/app.env` 里设一行：

```
EMAIL_FROM=Johnstone Bros <noreply@johnstonebros.ie>
```

在此之前，生产上点「发送邮件」会明确提示「发件域尚未验证」，不会假装成功。

**2. 给我 Odoo 的访问方式，客户的多个邮箱才能自动导进来**

现在系统里 1407 个客户只有 46 个有邮箱，一个多邮箱都没有 —— 当年从 Odoo 导客户时
只导了主邮箱，Odoo 里那些"一个客户下面挂好几个联系人"的数据从没导过。
需要下面两样之一：

- Odoo 服务器的 SSH + 数据库账号
- 或 Odoo 后台的 API 密钥

拿到之后我写个脚本一次性导进来。在那之前，联系人只能在客户资料页一个个手工加
（功能是好的，只是得靠人录）。
