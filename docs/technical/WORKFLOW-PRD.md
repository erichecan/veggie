# 蔬菜批发系统 · 运营主流程文档

> 本文档记录由运营人员主导的完整订单履约流程（14 个步骤）。
> 写入日期：2026-05-02

---

## 业务背景

本系统服务于蔬菜批发商，核心角色为：
- **运营人员（Operator）**：全程主导，负责建单、确认、协调仓库和配送
- **拣货员（Picker）**：在仓库按波次拣货
- **分货员（Sorter）**：将拣好的货按餐馆分配
- **司机（Driver）**：按行程配送，处理现场异常
- **会计（Accounting）**：对账核销、发票管理

---

## 主流程（14 步）

### 前置准备（非每日操作）

**步骤 0：系统基础配置**
- 商品目录（Products）已建立：名称、规格、单位、基础价格
- 客户数据库（Customers）已建立：餐馆信息、联系方式、地址
- 客户价格表（Pricelists）已建立：每家餐馆可设置独立折扣或固定单价

---

### 每日主流程

**步骤 1：运营建单（创建报价单）**
- 入口：`/operator/place-order`（代客下单页面）
- 操作：运营人员按餐馆选择商品、填写数量，生成报价单
- 结果：报价单以"草稿（Quotation）"状态保存
- 要点：此时订单尚未确认，不影响仓库操作

**步骤 2：报价单列表查看与管理**
- 入口：`/operator/quotations`
- 功能：查看所有草稿报价单；运营可从列表直接做快速编辑（分配司机批次）或进入详情修改
- 状态标签：`Quotation`（草稿）→ `Sales Order`（已确认）→ `Done`（已完成）

**步骤 3：电话确认 + 确认报价单**
- 操作：运营打电话与餐馆确认数量和价格
- 如需修改：进入报价单详情页 → 点击「编辑」→ 修改数量/商品/备注 → 「保存」
- 确认无误：点击 Action 菜单 → 「Confirm Quotation」
- 结果：报价单变为正式销售订单（Sales Order），可在拣货波次页看到"待生成波次"提示

**步骤 4：生成拣货波次**
- 入口：`/operator/waves`
- 操作：在"待生成波次的订单"面板中，勾选 2 个以上订单 → 点击「合并生成波次」
- 结果：系统按商品区域（叶菜区、根茎区等）自动汇总成一张拣货单；订单状态更新为 `wave_assigned`；同时自动创建一个"待指派司机"的配送行程占位

**步骤 5：拣货员执行拣货**
- 入口：`/picker`（拣货员角色界面）
- 操作：拣货员看到分配给自己的波次 → 逐项填写实际拣货数量 → 标记完成
- 结果：波次状态变为 `picked`

**步骤 6：分货员确认分货**
- 入口：`/sorter`（分货员角色界面）
- 操作：查看已完成拣货的波次 → 按餐馆查看各商品数量 → 司机核验货物 → 确认分货
- 结果：波次状态变为 `sorted`

**步骤 7：创建配送行程（分配司机）**
- 入口：`/operator/trips` → 「+ 新建行程」
- 操作（4 步向导）：
  1. 选择配送时段（AM 上午 / PM 下午）
  2. 选择要配送的餐馆/订单（已 confirmed/wave_assigned 状态的订单）
  3. 选择司机（从 DRIVER 角色用户列表中选择）
  4. 确认生成
- 结果：配送行程创建，司机可在 `/driver` 界面看到今日任务

**步骤 8：司机查看行程并出发**
- 入口：`/driver`（司机角色界面）
- 操作：查看今日行程 → 核验地址和商品列表 → 点击「出发」
- 结果：行程状态变为 `in_progress`

**步骤 9：司机到达餐馆配送**
- 操作（每家餐馆）：
  - **正常送达**：确认货物无误 → 点击「订单完成」→ 拍照签收
  - **异常情况**：选择异常类型（无人收货 / 拒收 / 部分退货换货）→ 填写原因 + 上传照片 → 记录为异常

**步骤 10：异常处理 → 退货/换货单**
- 异常在司机端记录后，自动在退货/换货页面生成对应记录
- 入口：`/operator/returns`
- 运营操作：查看退货记录 → 审核（批准 / 拒绝）→ 填写退款方式（按比例 / 固定金额）
- 结果：退货状态变为 `APPROVED` 或 `REJECTED`；批准的退货在会计页面显示为需处理标记

**步骤 11：会计对账核销**
- 入口：`/accounting`
- 操作：
  1. 查看当日已送订单列表
  2. 司机带回纸质签收单
  3. 逐一核对，扫码或手动勾选已回单的订单 → 「批量核销」
  4. 现付订单：核对司机带回现金金额与系统金额是否一致
- 结果：已核销订单标记完成；漏单进入追查流程

**步骤 12：运营生成发票**
- 入口：`/operator/invoices`（或从订单详情页点击「Create Invoice」）
- 操作：选择已完成的销售订单 → 选择要合并开票的订单 → 生成发票
- 发票状态：`draft（草稿）` → `posted（已确认）` → `paid（已付款）`
- 结果：发票列表显示每张发票的开票金额、含税/不含税明细、到期日期等

## 状态流转总览

```
报价单草稿 (Quotation)
    ↓ [确认]
销售订单 (Sales Order / CONFIRMED)
    ↓ [生成波次]
波次已指派 (WAVE_ASSIGNED)
    ↓ [拣货完成]
拣货完成 (PICKED)
    ↓ [分货完成]
已分货 (SORTED)
    ↓ [出发]
配送中 (IN_DELIVERY)
    ↓ [签收]
已完成 (COMPLETED)
    ↓ [开发票]
已开票 (INVOICED)
```
