# 配送调度台「分配完成」状态 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在配送调度台「确认出发」之前插入一个可反悔的纯进度标记「分配完成」，未出发前批次仍可自由修改。

**Architecture:** 给 `PickingWave` 加一个可空时间戳 `assignmentDoneAt` 表达标记；把「批次展示阶段」的优先级判定抽成纯函数 `waveStage` 供前端与测试共用；新增一个 `assignment-done` 路由做标记/撤销；`assign`/`unassign` 路由在改动订单时无条件清空该标记（拖拽自动退回分配中）；`dispatch`/`complete`/打印取数逻辑一律不动。

**Tech Stack:** Next.js（App Router，node_modules/next/dist/docs/ 为准）、Prisma + PostgreSQL、React 客户端组件、`node --test --import=tsx` 测试。

## Global Constraints

- 语言 TypeScript，禁止 `any`（沿用项目规则）。
- Prisma 加字段走 `db push` + 手写迁移 + `migrate resolve --applied`，**禁用 `migrate dev`**（shadow DB 会重放旧迁移失败）。
- 迁移目录命名 `YYYYMMDDHHMMSS_snake_name`，本次用 `20260703000002_wave_assignment_done`。
- API 路由第一行 `withAuth`（写操作必须鉴权）。
- 「分配完成」是纯进度标记：不改 `Order.status`、不回填 `Order.deliveryDate`、不推进 `WaveStatus`、不触发通知/拣货/Trip。
- 状态优先级恒为：`completedAt` > `dispatchedAt` > `assignmentDoneAt` > 分配中。
- 命令前缀：DB 相关脚本用 package.json 里的 `npm run db:*`（已带 `--env-file=.env.local`）。

```ts
export type WaveStage = 'assigning' | 'assignment_done' | 'in_transit' | 'completed'

export interface WaveStageInput {
  assignmentDoneAt: string | Date | null
  dispatchedAt: string | Date | null
  completedAt: string | Date | null
}

/**
 * 批次在配送调度台的展示阶段。优先级恒为：
 * completed > in_transit(已出发) > assignment_done(分配完成) > assigning(分配中)。
 */
export function waveStage(w: WaveStageInput): WaveStage {
  if (w.completedAt) return 'completed'
  if (w.dispatchedAt) return 'in_transit'
  if (w.assignmentDoneAt) return 'assignment_done'
  return 'assigning'
}
```

## Task 3: 新增 assignment-done 路由

**Files:**
- Create: `app/api/waves/[id]/assignment-done/route.ts`

**Interfaces:**
- Consumes: `prisma`、`withAuth`、`writeLog`、`serializeApi`（与同目录 `dispatch/route.ts` 一致）。
- Produces: `PUT /api/waves/:id/assignment-done`，body `{ done: boolean }`；成功返回序列化后的 wave（含 `assignmentDoneAt`）。

- [ ] **Step 1: 写路由**

Create `app/api/waves/[id]/assignment-done/route.ts`：

```ts
import { NextResponse } from 'next/server'
import { prisma } from '@/lib/db'
import { writeLog } from '@/lib/action-log'
import { withAuth } from '@/lib/auth'
import { serializeApi } from '@/lib/api-serializer'

/**
 * 分配完成标记：纯进度标记，可反悔。
 * body.done=true  → 回填 assignmentDoneAt=now（要求批次有订单、未出发）
 * body.done=false → 清空 assignmentDoneAt（撤销）
 * 不改订单状态/交货日期/波次理货状态，不触发任何下游动作。
 */
export async function PUT(req: Request, { params }: { params: Promise<{ id: string }> }) {
  const { id } = await params
  return withAuth(req, async (user) => {
    try {
      const { done } = (await req.json().catch(() => ({}))) as { done?: boolean }

      const wave = await prisma.pickingWave.findUnique({ where: { id } })
      if (!wave) return NextResponse.json({ error: '波次不存在' }, { status: 404 })
      if (wave.dispatchedAt) {
        return NextResponse.json({ error: '该批次已确认出发，无法更改分配完成标记' }, { status: 400 })
      }
      if (done && ((wave.orderIds as string[]) ?? []).length === 0) {
        return NextResponse.json({ error: '空批次不能标记分配完成' }, { status: 400 })
      }

      const updated = await prisma.pickingWave.update({
        where: { id },
        data: { assignmentDoneAt: done ? new Date() : null },
      })

      await writeLog({
        userId: user.userId, userEmail: user.email, userName: user.name,
        action: 'UPDATE', resource: 'picking-wave', resourceId: id,
        detail: `${done ? '标记分配完成' : '撤销分配完成'}：批次 ${wave.name ?? id}`,
      })

      return NextResponse.json(serializeApi(updated))
    } catch (error) {
      console.error('[PUT /api/waves/[id]/assignment-done]', error)
      return NextResponse.json({ error: '操作失败' }, { status: 500 })
    }
  })
}
```
