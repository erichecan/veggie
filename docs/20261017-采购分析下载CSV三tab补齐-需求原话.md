# 采购分析三个 Tab 都要有下载 CSV —— 需求原话

## 用户原话（20261017，附截图批注）

> 采购分析这里要有下载 csv 的功能,包括在 summary,drill-down,detail 三个不同的 tab 下,都有相对应的下载功能

截图：`Purchase Analysis` 页面 `Drill-down` Tab，批注用红色文字标出右上角缺一个「download」按钮。

## 核实现状

- **Summary**（`SupplierMonthMatrix.tsx`）：已有「下载 CSV」按钮，导出当前屏幕内容（含已展开的商品明细）。
- **Detail**（`PurchaseOrderDetailTable.tsx`）：已有「下载 CSV」按钮，导出当前采购单列表（不含展开的商品明细）。
- **Drill-down**（`PurchaseHierarchyTable.tsx`）：**原本没有**下载功能——这是本次要补的缺口。

## 实现

文件：`app/[locale]/classic/boss/reports/purchasing/PurchaseHierarchyTable.tsx`

新增 `exportCsv()`，跟 Summary/Detail 两个 tab 共用同一个 `lib/csv-export.ts` 的 `downloadCsv()`，前端拼 Blob 下载，不新开接口：
- 只导出屏幕上当前展开到的层级（跟界面状态一致，未展开的子节点不导出）；
- 每一行用前导空格表示层级缩进（`depth * 4` 个空格 + 节点 label），列为：产品/日期/供应商/采购单、金额、数量、平均价格；
- 总计行取组件已经算好的 `totalAmount`/`totalQty`，跟屏幕上那一行一致；
- 文件名带当前分组方式（`layout`）和日期范围，三个 tab 的文件名风格保持一致（`purchase-analysis-<视图>-...`）。

按钮样式、位置（表格上方工具条右侧）与另外两个 tab 保持一致。

验证：`npx tsc --noEmit` 全仓库 0 错误。因本机 Chrome 二进制缺失，无法用浏览器实测点击下载效果，建议你本地点一下「下载 CSV」核对导出的 CSV 内容。
